# 나만의 프롬프트 관리 프로그램

Python 기초 문법과 Git 버전 관리를 학습하기 위해 제작하는 콘솔 기반 프롬프트 관리 프로그램입니다.

## 개발 환경

- Python 3.10 이상
- Visual Studio Code
- Git 및 GitHub

## 예정 기능

- 프롬프트 추가
- 전체 목록 보기
- 카테고리별 조회
- 키워드 검색
- 상세 보기
- 즐겨찾기 관리

## 실행 방법

```bash
python prompt_manager.py
